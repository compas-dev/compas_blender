# Modules

The recovered integration includes:

- `compas_blender.conversions`: Convert geometry between COMPAS and Blender.
- `compas_blender.geometry`: Blender-backed geometry operations.
- `compas_blender.scene`: Draw COMPAS geometry and datastructures in Blender.
- `compas_blender.drawing`: Low-level drawing helpers.
- `compas_blender.objects`: Blender scene object utilities.
- `compas_blender.collections`: Collection management.
- `compas_blender.data`: Blender data cleanup helpers.
- `compas_blender.install`: Historical host installation helpers.

Host modules require the corresponding application APIs. Source docstrings and
the archived COMPAS API pages remain available in the repository. Automated API
rendering is deferred until the host imports and docstrings are migrated.
